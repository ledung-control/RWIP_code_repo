# 1. Common definitions
- **Scenarios** (as in the authors' evaluator): S0 nominal, θ0 = 0.10 rad, 60 s and 600 s; S1 mismatch ±30 % on mgl_eq, I_p,eq, K_t one at a time and the adverse combination (controller keeps nominal values, `P.g_theta_nom` fixed); S2 velocity impulse on θ̇ at t = 5 s, 1.0 and 2.0 rad/s.
- **Metrics:** IAE_θ, IAE_φ, RMSE_θ, overshoot, ts_θ, ts_φ, U_rms, φ(T), ρ (residual share), |a_bias| = |π(0)|, divergence flag. Per-seed values are always reported.
- **Pairing and statistics:** the same seed (same BC data, same initial networks) is paired across variants; paired differences, Hodges–Lehmann estimate, Walsh interval, exact sign-flip p; with n = 5 the smallest attainable two-sided p is 0.0625, with n = 10 it is 0.002. No multiplicity correction is claimed; every contrast is listed. Deterministic controllers (no seed) are reported as single values, not tested.
- **Seeds:** existing reported seeds 1–5 are kept for comparison. Tuning seeds (E1 only) are 101–103, disjoint from the reported ones. Seeds are fixed here and not changed after results are seen; a failed run is stored and explained, not silently replaced.
- **Stopping:** every training run uses the authors' fixed schedule (60 BC episodes, 3000 BC iterations, 20 warm-up episodes, 18 fine-tune episodes, actor LR 1e-5 → total drift 0.36 unit, γ and scaling as stated per experiment). No early stopping on test metrics.
- **Outputs per run:** configuration struct, seed, MATLAB version, script and file dates, wall time, per-run metrics CSV, checkpoint (new folder), console log.

# 5. Robustness and head-to-head
**E5 (extended distributions).** Monte-Carlo on S0-type runs, 100 draws per factor (fixed now): initial state θ0 ~ U[−0.15, 0.15], θ̇0 ~ U[−1, 1], φ0 ~ U[−2, 2]; parameter mismatch each of mgl, I_p, K_t ~ U[−30 %, +30 %] (controller nominal); sensor noise on θ (σ = 1e-3 rad) and φ̇ (σ = 1e-2 rad/s); input delay {0, 5, 10} ms; actuator saturation ±24 V as in the paper. Policies: PSO-FLC, SMC-ESO, hybrid, and the 10 stored networks raw and π(0)-removed (E1/E2 networks are added if they exist). Metrics: IAE_θ, IAE_φ (60 s), pass rate against the design criterion; paired changes per draw. Noise and delay models are **new implementations** (not in `sim_rwip_v13.m`). Hardware: not possible here and stays "not done".
**E6 (head-to-head).** Only if a recent method's description and code of sufficient detail are found and the plant can be matched; otherwise a qualitative comparison stating which conditions are not equivalent. No numbers from other plants are used to claim better or worse. Status at the date of this protocol: no code located. Not run.

Comparison: PSO-FLC, SMC-ESO and LQR under **both** outer-loop gain sets (separates the cascade-gain effect from the inner-loop law), S0/S1/S2, 1 kHz and 100 Hz (outer loop + inner loop ZOH). ## v2.0 — E3b: PSO-FLC retuned at the matched rate (written before any E3b run; 1 Nov 2026)

**Decision.** The authors asked that the remaining requests except hardware be carried out. R2-3 asks for matched-rate and comparable-budget controls. v1.0 provided for a retuned variant with the same PSO budget only on the authors' approval; the approval is given.
**Question.** Does the PSO-FLC, when its ten parameters are re-optimized with the paper's PSO (30 particles × 20 iterations = 600 cost evaluations, same cost, same four specifications, same bounds, same swarm coefficients and initialization scheme) under the 100 Hz sampling of the outer loop and the fuzzy inner loop, keep its advantage over the agents (evaluated at 100 Hz) in the E3 scenarios?
**Definition.** Cost J, specifications (OS ≤ 0.006, t_sθ ≤ 3.0 s, |φ| peak ≤ 0.52, t_sφ ≤ 11.0 s), weights, bounds, windows and swarm settings = `pso_rwip_v13.m`. Only the evaluator changes: `sim_rwip_r5` (RK4, 1 ms plant step, ctrlTs = 10 ms zero-order hold on the outer loop and fuzzy inner loop, 30 s, θ0 = 0.10 rad) replaces the Simulink model, and the FIS is rebuilt from (s_e, s_de, s_u) exactly as in `buildFIS`. Initialization as in the paper (particles 1–3 the three seed points; 75 % of the swarm Gaussian around particle 1, σ = 8 % of value; the rest uniform). Five independent PSO runs with rng seeds 20260806 + k, k = 0…4 (20260806 is the paper's seed). No seed is dropped; all five are reported.
**Control check (smoke, before the PSO).** The cost of the official solution is evaluated with the same evaluator at 1 kHz and at 100 Hz, and the time per evaluation is measured. The 1 kHz value is compared with the stored J = 0.314771 (the Simulink model uses ode4 with a 10 ms step, so a small difference is expected and will be reported, not corrected).
